# Cuestionario SUS

Escala por afirmación: 1 = totalmente en desacuerdo; 5 = totalmente de acuerdo.

1. Creo que usaría este sistema con frecuencia.
2. Encontré el sistema innecesariamente complejo.
3. Pensé que el sistema era fácil de usar.
4. Creo que necesitaría ayuda de una persona técnica para usar este sistema.
5. Encontré que las funciones del sistema estaban bien integradas.
6. Pensé que había demasiada inconsistencia en el sistema.
7. Creo que la mayoría de las personas aprenderían a usarlo rápidamente.
8. Encontré el sistema muy incómodo de usar.
9. Me sentí seguro al usar el sistema.
10. Necesité aprender muchas cosas antes de poder usar el sistema.

## Cálculo

- Ítems impares: restar 1 a la respuesta.
- Ítems pares: restar la respuesta de 5.
- Sumar los diez valores y multiplicar por 2.5.
- El resultado individual y el promedio grupal se expresan sobre 100.

Registrar el puntaje de cada participante y el promedio del grupo en el informe; no completar resultados hasta realizar las sesiones.
